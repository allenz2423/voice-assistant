# Skill: i3 (X11 Tiling Window Manager)

## Overview
i3 is a dynamic, manual tiling window manager designed for the X11 Window System. It uses tree data structures for container management and is controlled via `i3-msg` communicating over UNIX domain sockets.

## Environment Detection
- `I3SOCK` environment variable is defined.
- `XDG_CURRENT_DESKTOP=i3`
- Binary: `/usr/bin/i3-msg`
- Socket: `/run/user/<uid>/i3/ipc-socket.<pid>` or `/tmp/i3-*.sock`

## Assistant Built-in Tools
- **Switch Workspace**: `workspace_control(action="switch", workspace="<id>")` (runs `i3-msg workspace <id>`)
- **Move Active Window to Workspace**: `workspace_control(action="move", workspace="<id>")` (runs `i3-msg move container to workspace <id>`)
- **Focus Window**: `focus_window(target="<target>")` (runs `i3-msg [class="(?i)<target>"] focus` or `wmctrl -a "<target>"`)
- **List Windows**: `list_windows()` (parses `i3-msg -t get_tree` or `wmctrl -l`)
- **Launch Application**: `launch_application(app_name="<name>")` (executes via `i3-msg exec <cmd>`)
- **Close Window**: `close_application(app_name="<name>")` (runs `i3-msg [class="(?i)<name>"] kill`)

## Direct CLI Commands (via `run_bash_command`)
When advanced window layout or container actions are requested, execute `i3-msg <command>`:

### Workspaces
- Switch to workspace: `i3-msg workspace <number_or_name>`
- Move focused container to workspace: `i3-msg move container to workspace <number_or_name>`
- Move workspace to different monitor: `i3-msg move workspace to output <output_name>`
- Query workspace list: `i3-msg -t get_workspaces`

### Window Layout & Containers
- Toggle floating mode: `i3-msg floating toggle`
- Toggle fullscreen: `i3-msg fullscreen toggle`
- Switch layout mode: `i3-msg layout toggle split` (alternatively: `stacking`, `tabbed`, `splitv`, `splith`)
- Move container direction: `i3-msg move <left|right|up|down>`
- Focus direction: `i3-msg focus <left|right|up|down>`
- Move to scratchpad: `i3-msg move scratchpad`
- Cycle / toggle scratchpad: `i3-msg scratchpad show`
- Kill focused window: `i3-msg kill`

### Session & System
- Restart i3 in-place: `i3-msg restart`
- Reload i3 configuration: `i3-msg reload`
- Lock session: `i3lock` or `loginctl lock-session`
