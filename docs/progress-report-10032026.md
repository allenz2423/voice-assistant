## Changes

- Replaced game-specific tool filtering with a general rule for requests that launch/open an app and then perform work inside it. These requests keep app discovery, launch, screenshot/observation, focus, and desktop interaction tools while dropping unrelated schemas.
- Added a desktop no-progress circuit breaker. It compares normalized action parameters with a coarse screenshot signature so cursor movement and tiny live screen changes do not hide a stuck click loop. Nearby click coordinates are grouped into 48-pixel cells to tolerate small coordinate jitter. The live Shenzhen run showed why this general safeguard needs the spatial tolerance.
- Changed OCR to use PP-OCRv6 small by default, with medium available as a configuration option. The ScreenOCR wrapper is now available on demand even when OmniParser is off; its models remain unloaded until a screen request asks for OCR. OCR defaults to CPU independently of the visual detector, and GPU use must be selected explicitly.
- Capped model-requested screenshot waits at the configured app-aware delay. The configured delay remains adjustable; model calls can shorten it. Browser detection now requires word-bounded browser names, avoiding matches on unrelated app-name fragments.
- Replaced the hard-coded 600-second HTTP request timeout with configurable defaults of 45 seconds for text and 90 seconds for image requests, both capped at 120 seconds.
- Added general system guidance to match visible controls to the user’s requested outcome and stop repeating actions when the screen does not change.
- Made standalone `computer_control(action="wait")` a supported alias for a fresh inspection with a bounded delay. Qwen emitted this form twice despite the prior schema. In the follow-up run, Adam returned fresh screen state without an invalid-tool recovery turn; the overall attempt dropped from 34.89 to 32.50 seconds, with target selection still the limiting issue.
- Added generic Steam library discovery to installed-application search and launch. Adam can now find titles from Steam's local `appmanifest_*.acf` files, including titles in additional Steam libraries, and launch a matched title through its `steam://rungameid/...` URI. This addresses missing app-catalog entries for Steam apps without adding game-specific navigation. Custom launch arguments are rejected for these entries.
- Added a per-request repeated-launch guard. If an app launch command is accepted but its window cannot be verified, Adam may inspect the desktop, but the same unverified app launch cannot be issued again during that request. The guard is app-agnostic.
- Tried outlining OCR regions directly on model screenshots. On the same stress prompt, Qwen still clicked the conceptMAIL icon and the unchanged-screen breaker stopped it after 42.47 seconds. The annotated image was larger and the task did not improve, so the overlay code was removed.
- Kept existing X11 computer-control fixes in place for cursor movement and drag behavior, which were needed to make desktop inputs reliably dispatch in the isolated test session.
